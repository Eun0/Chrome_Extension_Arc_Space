크롬에서 쓰는 Arc 사이드바

세로 탭, 스페이스 전환, 24시간 지난 탭 자동 정리까지. Arc를 쓰던 방식 그대로 크롬 사이드패널에서 쓸 수 있게 만든 개인용 확장입니다.

설치 화면 구성 스페이스 즐겨찾기와 고정 드래그 분할 화면 자동 정리 미니 플레이어 아이콘 꾸미기 설정과 단축키 한계

설치

  1. 저장소를 내려받습니다. git clone https://github.com/Eun0/Chrome_Extension_Arc_Space.git
  2. 크롬 주소창에 chrome://extensions를 열고 오른쪽 위 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드합니다를 누르고 내려받은 폴더를 고릅니다.
  4. 툴바의 Arc Space 아이콘이나 ⌘ B로 사이드패널을 엽니다. Arc처럼 왼쪽에 두려면 chrome://settings/appearance에서 사이드 패널을 왼쪽에 표시로 바꿉니다.
  5. Chrome 121 이상에서 동작합니다. 분할 화면은 Chrome 155, 사이드패널 닫기 단축키는 Chrome 141 이상이 필요합니다.
Layout

화면 구성

위에서 아래로 Arc와 같은 순서입니다.

  • 공통 즐겨찾기맨 위 아이콘 그리드. 모든 스페이스에서 똑같이 보입니다.
  • 스페이스 이름지금 스페이스. 더블클릭하거나 ⋯을 누르면 편집합니다.
  • 스페이스 고정이름과 가로선 사이. 이 스페이스에만 있고, 닫아도 남으며 자동 정리되지 않습니다.
  • 일반 탭가로선 아래. 24시간 동안 안 보면 자동으로 정리됩니다.
  • 재생바음악·영상 탭을 보고 있지 않을 때 나타납니다.
  • 하단 독아카이브 · 스페이스 아이콘 · 설정.
Spaces

스페이스 전환

창 하나 안에서 업무·개인·공부처럼 탭 묶음을 바꿔 씁니다. 바꾸면 지금 탭들은 저장되고 닫히며, 고른 스페이스의 탭이 열립니다. 크롬 위쪽 탭 바에는 지금 스페이스의 탭만 보입니다.

  • 하단 독의 스페이스 아이콘을 클릭해서 전환합니다.
  • 사이드패널 위에서 가로 스크롤(MX Master 사이드 휠, 트랙패드 좌우 스와이프)로 이전·다음 스페이스로 넘어갑니다.
  • 단축키 ⌥ ⇧ ← / →로도 넘어갑니다.
  • 전환할 때 바로 볼 탭 하나만 로드하고, 나머지는 클릭할 때 로드해서 빠릅니다.
  • 아이콘끼리 끌어서 순서를 바꾸고, 우클릭으로 이름·이모지·색을 편집합니다.
Favorites & Pins

즐겨찾기와 스페이스 고정

Arc처럼 두 단계로 고정합니다. 둘 다 탭을 닫아도 항목이 남고, 다시 클릭하면 열립니다.

  • 공통 즐겨찾기: 열면 크롬 고정 탭으로 떠서 스페이스를 바꿔도 남습니다.
  • 스페이스 고정: 다른 페이지로 이동하면 제목 앞에 /가 붙습니다. 우클릭으로 원래 주소로 돌아가거나 지금 주소로 바꿉니다.
  • 탭을 우클릭해서 이 스페이스에 고정 또는 즐겨찾기에 추가를 고르거나, 끌어다 놓아서 추가합니다.
Drag & Drop

끌어서 정리하기

놓는 자리에 따라 동작이 달라집니다. 끄는 동안 놓을 수 있는 곳에 스페이스 색 선이 생깁니다.

끄는 것놓는 곳결과
일반 탭맨 위 아이콘 영역공통 즐겨찾기에 추가

고정 ↔ 즐겨찾기서로의 영역종류만 바뀌고 탭은 유지
Split View

분할 화면

탭을 다른 탭 줄의 가운데에 놓으면 두 탭을 한 화면에 나란히 띄웁니다. 줄의 위·아래 가장자리에 놓으면 순서만 바뀝니다.

  • 분할된 두 탭은 사이드패널에서 한 줄에 반씩 보입니다.
  • 우클릭으로 분할 해제, 둘 다 닫기를 할 수 있습니다.
  • 스페이스를 바꿨다 돌아와도 분할 상태가 복원됩니다.

크롬 기본 Split View 기능을 쓰며 Chrome 155 이상이 필요합니다.

Auto Archive

24시간 지난 탭 자동 정리

마지막으로 본 지 24시간이 지난 일반 탭을 닫고 아카이브로 옮깁니다. 10분마다 확인합니다.

  • 즐겨찾기, 스페이스 고정, 지금 보는 탭, 소리 나는 탭은 닫지 않습니다.
  • 지금 쓰지 않는 스페이스에 저장된 탭도 같은 기준으로 정리됩니다.
  • 아카이브는 날짜별로 묶이고 검색할 수 있으며, 클릭하면 다시 열립니다.
  • 기준 시간은 설정에서 끄기, 6시간, 12시간, 24시간, 3일, 7일 중에서 고릅니다.
Mini Player

미니 플레이어

음악·영상이 나오던 탭에서 다른 탭으로 넘어가면 하단에 재생바가 생깁니다. 마우스를 올리면 위로 펼쳐지며 재생 중인 제목이 보입니다.

  • 이전 · 재생/일시정지 · 다음, 음소거를 지원합니다.
  • 사이트가 브라우저에 등록한 미디어 동작(키보드 미디어 키와 같은 경로)을 불러서, 숨은 탭에서도 바로 넘어갑니다.
  • 사이트별로 처음 누를 때 접근 허용을 한 번 묻습니다. 설치 후 음악 탭을 한 번 새로고침하면 가장 잘 동작합니다.
Custom Icons

아이콘 꾸미기

즐겨찾기와 스페이스 고정의 아이콘을 바꿀 수 있습니다. 우클릭해서 아이콘 바꾸기를 누르세요.

  • 색 블록: 배경색 위에 글자 1~2자. 배경색과 글자색은 고르거나 직접 지정합니다.
  • 이모지: 이모지나 글자 하나.
  • 이미지: 파일을 고르면 64×64로 잘라 저장합니다.
  • 기본: 사이트 파비콘으로 되돌립니다.

Limits

크롬이라서 생기는 한계

  • 크롬 위쪽 가로 탭 바는 확장으로 숨길 수 없습니다.
  • 사이드패널의 최소 폭은 크롬이 정해서 더 좁게 줄일 수 없습니다.
  • 스페이스를 바꾸면 탭을 새로 열기 때문에 스크롤 위치와 입력 중인 내용은 유지되지 않습니다.
  • 창 하나 기준으로 설계했습니다. 창이 여러 개면 스페이스 전환은 사이드패널이 열린 창에만 적용됩니다.
  • 가로 스크롤 전환은 마우스가 사이드패널 위에 있을 때만 동작합니다.
